# Карты

Все карты собираются меню **Tools > FPS > Build All Maps**. Сборка обновляет список сцен в Build Settings: `RangeBuilder.SceneOrder` + `SetBuildScenes`.

После сборки запускайте **Tools > FPS > Check Maps**, отчёт пишется в `Logs/fps_check.txt`. Проверка по каждой карте:
- точки спавна на навмеше, не внутри объектов и связаны между собой;
- доля недостижимых точек для подбираемых способностей.

### Карты из демо-сцен (`MapBuilderPacks.cs`, `MapBuilderDesert.cs`)
`BuildFromPack(PackMap)` делает следующее:
1. копирует демо-сцену в `Assets/Scenes`;
2. убирает её камеры, пост-обработку и солнце;
3. ставит коллайдеры на меши без них;
4. обносит играбельный прямоугольник невидимыми стенами (`Bounds`) и ставит ловящий пол;
5. запекает навмеш внутри и сохраняет его рядом со сценой;
6. выбирает точки спавна на самой большой связной области навмеша;
7. добавляет игрока, ботов и `MatchManager`.

Настройки `PackMap`:
- `core` — играбельная область;
- `light` — свет и пост-обработка;
- `floorY` — пол для карты на крыше: всё ниже него игнорируется;
- `ceilY` — потолок навмеша для крытой карты. У «Склада боеприпасов» он 8 м: без него самой большой областью оказывалась плоская крыша, и бой шёл там;
- `fixups` — правки конкретной карты.

Правки пустынной базы. Демо ithappy — целая авиабаза на 1,5 км дюн с меш-коллайдером на каждом объекте, поэтому:
- сплайновый трафик удаляется, у припаркованной техники выключаются аниматоры;
- мелочь дальше 35 м от забора удаляется;
- декорации за забором остаются видны, но без коллайдеров;
- трава, кусты, провода, флаги, лопасти и всё анимированное становится проходимым.

### Фабрика (`MapBuilderFactory.cs`)
Планировка процедурная (стены и лестницы из общего набора `RangeBuilder`), обставлена пропсами HQ Warehouse Kit.
- **Материалы кита** переводятся из Built-in Standard в URP/Lit (`ImportedMaterialFixer.Convert`).
- **Коллайдеры.** У кита их нет: `Prop()` ставит пропс по его габаритам (независимо от пивота) и надевает box collider.
- **Стеллажи** заставлены коробками: они сплошные укрытия, значит и выглядеть должны сплошными.
- **Пол.** Текстура бетона — атлас с синей полосой, поэтому чистый бетон вырезается в `Generated/Textures/FAC_Concrete.asset`.
- **Навмеш** за стенами здания запрещён объёмами `NoNav`.

## Проходимость и точки возрождения
- **Двери не перекрыты.** В демо-сценах на домах и стенах стоят большие box-коллайдеры, они закрывали дверные и оконные проёмы. `PackExactColliders` выключает такие коллайдеры (больше 1,8 м, на статичных объектах) и ставит вместо них точный `MeshCollider` по мешу объекта. Число заменённых пишется в строку сборки: «N box colliders made exact».
- **Агент навмеша** `Humanoid`: радиус 0,35, рост 1,8, ступенька 0,75, уклон 45° (`ProjectSettings/NavMeshAreas.asset`). С прежним радиусом 0,5 двери шириной около метра не проходили.
- **Проверка карт** (`MapCheck`) считает достижимость через `NavMesh.CalculatePath`. Связность по треугольникам давала ложные «карманы» на стыках тайлов. Все 14 карт сейчас: 0 точек вне навмеша, 0 заблокированных, 0 оторванных.
- **Появление не под картой и не на крыше.** `MatchManager.GetSpawn` прижимает точку к навмешу только в пределах 1,5 м и только на её же уровне (разница по высоте меньше 0,8 м). Раньше поиск в 3 м мог поставить игрока на край крыши или этажом ниже.
- **Миникарта и режимы с целями** строятся по навмешу и точкам возрождения во время игры (см. `Modes/README.md`). После пересборки карты обновлять ничего не нужно.

## «Затопленная деревня»
Пак Flooded Grounds исключён в git и сейчас удалён из проекта. Сцена `Map_Flooded` осталась, но без него сломана: нет префабов и навмеша. Поэтому:
- `SetBuildScenes` не включает её в сборку, пока нет папки `Assets/Flooded_Grounds`;
- меню скрывает карты, которых нет в сборке;
- «Война дронов» запускается на пустынной базе (`MapEntry.alt`).

После повторного импорта пака всё вернётся само при следующей сборке карт.
