# Классы, команды и способности

## Классы (`PlayerClass`, `ClassDB`)
Класс выбирается вверху окна снаряжения (`LoadoutPanel`) и хранится в `fps.loadout.class`. Оружие запоминается отдельно для каждого класса: `fps.loadout.<Класс>.primary/secondary`. Сменить класс можно и во время матча (Esc), он применится при возрождении. Каждый класс носит только своё оружие: `ClassDB.AllowsPrimary/AllowsSecondary`, а `Loadout.ApplyPlayerChoice` подставляет оружие класса, если сохранённое не подходит.

### Где что
- **`ClassAbility`** (на игроке, порядок исполнения 70). Пассивные бонусы пересчитываются каждый кадр от сохранённых базовых значений: скорости `PlayerMotor` и `WeaponController.ReloadSpeed`. Клавиша класса: `BindAction.ClassAbility`, по умолчанию 3, переназначается в настройках.
- **`ClassHUD`** показывает:
  - слот способности над слотом подбираемой способности: перезарядка, время действия, число гранат РПГ;
  - подсказку «[3] держать — поднять» с полосой;
  - короткие сообщения;
  - экран ожидания медика.
- **`ReconVision`** + `Resources/FPS_ReconXRay.shader`. Красные силуэты врагов рисуются через `Graphics.RenderMesh` по мешам рига с `ZTest Greater`, как в тепловизоре дрона.
- **РПГ-7.** `WeaponController.launcher`:
  - ракета — копия модели из трубы (`RocketProjectile.CreateLauncherRocket`) с огнём и взрывом: урон 160, радиус 7 м;
  - выстрел уходит по сети как `Msg.Launcher`;
  - пустая труба показывается без ракеты, перезарядка вставляет новую.
- **Боты** (`CombatBot.Classes.cs`) получают класс и его оружие при появлении:
  - штурмовик колет адреналин в бою ниже 45 % здоровья;
  - медик лечится ниже 50 % и поднимает павших союзников в 15 м, если не в бою;
  - инженер стреляет из РПГ на 12–60 м раз в 18–26 с.

## Командный бой (`Teams`, `GameMode.TeamDeathmatch`)
- **Режим.** «Командный бой» стоит по умолчанию в «Одиночной игре» (селектор «Режим»). В сетевой игре это режим «КОМАНДНЫЙ БОЙ».
- **Команды и счёт.** Синие и красные. Огня по своим нет. Лимит убийств команды — лимит игрока ×2.
- **Подбор команд.** Боты встают в меньшую команду. В первые ~80 с игроки появляются на своей стороне карты.
- **Возрождение медиком.** Павший лежит 7 с (`Teams.ReviveWindow`), за это время медик может поднять его. Поднятый получает 50 % здоровья, своё оружие и патроны, и не переносится к точке возрождения. Пробел — возродиться сразу.
- **Сеть.** Команда идёт в ростере; хост ставит её и на прокси удалённого игрока у себя, иначе его боты, зоны и подсчёт живых не видели команду клиента. Протокол 4 (с режимами с целями и интернет-игрой). Подъём — сообщение `Msg.Revive` владельцу.
- **Интерфейс.**
  - строка матча показывает счёт команд;
  - лента убийств: союзники синие, враги красные;
  - таблица сгруппирована по командам и показывает классы;
  - в конце матча — ПОБЕДА / ПОРАЖЕНИЕ / НИЧЬЯ;
  - ники союзников (`TeamNameplates`) — синие над головой, видны сквозь стены; павший союзник — мигающий зелёный «+ ник +»; ников врагов нет (сетевые таблички `NetProxy` в командных режимах скрыты).
- **Те же командные правила** действуют в режимах с целями — «Захват точек», «Закладка бомбы», «Штурм» (`Teams.IsTeamMode`). Там счёт команды — очки, раунды или взятые точки, а не убийства. В «Закладке бомбы» медик поднимает только в первые 7 с после гибели. Подробно: `Modes/README.md`.
